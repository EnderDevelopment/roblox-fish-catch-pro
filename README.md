# FishCatchPro

FishCatchPro is a Roblox script designed to enhance the Kick for Pets game by adding an interactive bar system for catching fish. The bar moves with the player's mouse, and players must align it with a target to successfully catch the fish. This script includes a main menu and gameplay mechanics to provide a seamless and engaging experience.

## Install

1. Open Roblox Studio.
2. Create a new place or open an existing one.
3. Navigate to the `ServerScriptService` folder.
4. Create a new script and name it `MainMenu`.
5. Paste the contents of `MainMenu.lua` into the script.
6. Create another new script and name it `Gameplay`.
7. Paste the contents of `Gameplay.lua` into the script.
8. Save and play the game in Roblox Studio.

## Use

1. Launch the game in Roblox Studio.
2. The main menu will appear with options to Play, Settings, and Quit.
3. Click the Play button to start the game.
4. Use the mouse to move the bar and align it with the target to catch the fish.
5. If the bar is aligned with the target, the fish is caught; otherwise, it is lost.
